# BeeClean - iOS App

A native iOS app built with Swift and SwiftUI for smart phone cleanup and storage optimization.

## Features

- **Smart Storage Cleanup** - AI-powered duplicate detection and junk file removal
- **Email Cleaner** - Bulk delete promotional emails and manage subscriptions
- **Contact Manager** - Find and merge duplicate contacts
- **Secret Vault** - PIN-protected private photo/video storage
- **Charging Animations** - Beautiful battery charging animations
- **File Compression** - Compress media files to save space

## Requirements

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Getting Started

1. Open `BeeClean.xcodeproj` in Xcode
2. Select your target device/simulator
3. Build and run (⌘R)
